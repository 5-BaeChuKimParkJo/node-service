# 짧은 체험 경매

사용자가 승인한 범위: 관리자에서 5분/30분/24시간 데모를 생성하고 고객이 입찰,
마감, 낙찰자 Toss 테스트 결제를 이어서 체험한다. 실제 배송/실결제는 제공하지 않는다.

## 선택한 방식

기존 관리자 데모 생성과 경매/결제 흐름을 확장한다. 별도 체험 서비스나 기존 데이터
초기화는 필요하지 않다. 운영 경매를 강제 종료하는 방식은 체험 시간을 보장하지 못한다.

- POST demo body의 선택 필드는 `durationMinutes`: 숫자 5, 30, 1440만 허용한다.
  생략/빈 객체는 기존 24시간 정시 일정을 유지한다. 관리자 UI 기본값은 5분이다.
- 5/30분은 서버의 생성 요청 시각부터 정확한 기간을 사용한다. 일반 생성/수정의
  정시 규칙과 일반 생성 최소 1시간 규칙은 유지한다.
- 저장된 경매 조회와 관리자 조회는 분 단위 시각을 읽을 수 있어야 한다.
- 기존 demoTemplateUuid 기록에서 파생한 public detail `isDemo`만 노출한다.
  원본 UUID는 public HTTP/Outbox에 노출하지 않는다. 제목만 바꿔 데모를 위조할 수 없다.
- 자동 보충은 기존 24시간 경로를 사용한다. 트랜잭션/Outbox/입찰/결제 권한은 유지한다.
- 관리자 모달: 기간 선택, 실제 생성 일정, 고객 화면으로 이동하는 링크.
- 고객 상세: 체험 표시, 입찰→마감/낙찰→테스트 결제 단계, 공유 계정/테스트 환경 안내.
  마감 시 한 번 서버 결과를 새로 조회한다. 낙찰자 결제는 기존 서버 권한 검증을 사용한다.

## 완료 기준

선택/기본/잘못된 JSON/일반 경매 우회 방지, 분 단위 저장·조회·Outbox 및 마감 후
입찰 거절/낙찰자 결제 자격을 테스트한다. 관리자와 고객 모바일/데스크톱을 검증한다.
운영 검증은 조회와 UI 확인만 한다. 테스트 입찰/결제는 운영에 자동 생성하지 않는다.
